# daily-money-tracker2
บันทึกรายรับรายจ่าย — แอปบันทึกรายรับรายจ่ายประจำวันที่ใช้งานง่ายบนมือถือ เพิ่มรายการได้เร็วและแบ่งหมวดหมู่ได้ เช่น อาหาร เดินทาง ช้อปปิ้ง และอื่น ๆ มีหน้าสรุปยอดรายเดือนที่แสดงรายรับ รายจ่าย ยอดคงเหลือ และกราฟสัดส่วนตามหมวดหมู่ ข้อมูลทั้งหมดเก็บไว้ในเครื่องและใช้งานแบบออฟไลน์ได้
